# How-To Guides

This folder contains the working conventions for the Playwright API automation project.

## Guides

- [Architecture overview](./architecture-overview.md): how tests, fixtures, services, clients, models, assertions, configuration, logging, and reporting fit together.
- [Framework conventions](./framwork-conventions.md): naming, responsibilities, TypeScript patterns, environment handling, and extension rules.
- [Testing conventions](./testing-conventions.md): how to write, tag, run, debug, and report API tests.

## Recommended reading order

1. Read the [architecture overview](./architecture-overview.md) before adding a new endpoint.
2. Use [framework conventions](./framwork-conventions.md) while implementing the client, service, model, fixture, or assertion changes.
3. Use [testing conventions](./testing-conventions.md) when adding or running coverage.

These documents describe this API project only. The sibling UI automation project has its own structure and documentation.
